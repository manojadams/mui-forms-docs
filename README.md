## 🚀 About This Project

This repository contains the comprehensive documentation and interactive examples for the **mui-forms library** — a modern, schema-driven form builder for React applications using Material-UI components.

## ✨ Key Features

- 📖 **Comprehensive Guides** — From basic setup to advanced patterns
- 🎨 **Interactive Examples** — Live, editable form examples you can customize
- 🎯 **Practical Tutorials** — Real-world use cases like payment forms, feedback forms, address forms
- 📱 **Responsive Design** — Mobile-first documentation experience
- 🔧 **API Reference** — Complete documentation of all form configuration options
- 🎭 **Custom Components** — Learn to build and integrate custom form fields
- 🚦 **Error Handling** — Advanced validation and error management patterns
- ⚡ **Performance Tips** — Optimization guides and best practices

## 📚 Documentation Structure

The documentation covers:

## 🛠️ Development Setup

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone and install dependencies
git clone <repository-url>
cd mui-forms-docs
npm install
```

### Running Locally

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

The site will be available at `http://localhost:3000`
